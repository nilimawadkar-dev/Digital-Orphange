# Digital Orphanage #

A web-based platform designed to streamline management, donor engagement, and visitor tracking for orphanages. This application provides a structured layout to manage operational data, show case community impact, and handle visitor records efficiently.

This project is built using server-side web technologies and includes modular components for managing database interactions and user interfaces.

## 🚀 Live Demo
View the live repository here: https://github.com/nilimawadkar-dev/Digital-Orphange.git

## ✨ Features
* **Visitor Management System**: Dedicated components (`visitor.aspx`) to capture, track, and log visitor entries and appointment schedules.
* **Server-Side Integration**: Built-in backend code-behind structure handling core data processing and page behavior securely.
* **Responsive Visual Components**: Structured galleries and visual assets optimized to display updates, events, and gallery media.
* **Dynamic Form Control**: Fully managed designer profiles ensuring seamless interface scaling and validation checks.

## 🛠️ Tech Stack
* **ASP.NET (Web Forms)**: Main framework structure utilizing server-side controls (`.aspx`).
* **C# (C-Sharp)**: Strong code-behind implementation (`.aspx.cs`) processing the business logic, request routing, and data structures.
* **HTML5 & CSS3**: Core front-end presentation layer for semantic layout styling and user interface styling.

## 📂 Project Structure
```text
├── visitor.aspx # Core front-end markup for visitor portals
├── visitor.aspx.cs # Backend C# programming logic and event handlers
├── visitor.aspx.designer.cs # Automatically managed UI designer layouts
└── visitor1.jpg # Asset storage for web images and media
```

## 💻 Getting Started

### Prerequisites
To run this application locally with full backend capability, ensure you have the following installed:
* [Visual Studio](https://microsoft.com) or [VS Code](https://visualstudio.com)
* [.NET SDK / IIS Express](https://microsoft.com)

### Execution Steps
1. **Clone the repository:**
   ```bash
   git clone https://github.com.git
   ```
2. **Open the project:**
   * Open the project directory within Visual Studio or VS Code.
3. **Run the local environment:**
   * If using Visual Studio, press `F5` to start debugging with IIS Express.
   * If using VS Code with the **Five Server** extension, right-click `visitor.aspx` and select **"Open with Five Server"** to review the webpage structure.
